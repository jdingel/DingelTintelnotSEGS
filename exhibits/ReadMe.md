This task produces a PDF containing all the exhibits appearing in "Spatial Economics for Granular Settings".

It also produces `exhibits_maintext.pdf`, which only contains the exhibits in the main text of the paper, and `exhibits_maintext_fast.pdf`, which further omits the interactive fixed-effects specification and the fixed-$\nu$ and Monte Carlo simulations that need to be run on a computing cluster.
The fast pipeline can be run in under 30 minutes on a personal computer.
