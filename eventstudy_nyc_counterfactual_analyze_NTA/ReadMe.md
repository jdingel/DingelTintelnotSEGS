# eventstudy nyc counterfactual analyze NTA

This task compares models' predictive performance after aggregating the tract-level predictions up to Neighborhood Tabulation Areas (NTA) defined by the New York City Department of City Planning.
We mainly look into slope, intercept, and MSE.


Because this task aggregates tract-level predictions to produce NTA-level predictions,
we have used the suffix "post_aggregated" in some filenames.
This distinguishes them from the NTA-level models in `eventstudy_nyc_NTA_*` tasks.

This task requires a tract list originally generated by an upstream task (`LODES_findemploymentspikes`). While the Makefile was designed to fetch this list automatically, this setup can occasionally fail if the upstream output does not exist yet, and if the environment uses an older shell version with limited support for certain commands.
To ensure smooth usage, the required file (`LODES_findemploymentspikes/output/nyc_20102012_spikes_list.txt`) has been committed to this repository. If you encounter errors related to tract list generation, we recommend running the upstream task first to regenerate the file, or simply using the version already included in this repository.

## Output:
* `nyc_tract_NTA_crosswalk.dta`: NYC tract-to-NTA crosswalk.
* `$(tract)_contrastchanges_NTA.tex`: compares observed and predicted employment changes at the NTA level for a given tract, and reports regression results (including MAE and MSE) for each model.
* `MSE_MAE_values_NTA.txt`: compiles MSE and MAE for all tracts and model specifications evaluated in `*_contrastchanges_NTA.tex`.
* `slopes_intercepts_NTA.txt`: summarizes the estimated regression coefficients from `*_contrastchanges_NTA.tex` for each tract and model specification.
* `summary_MSE_NTA_post_aggregated.tex`: provides a summary statement comparing the predictive performance of the CBM and CSP across all tracts, aggregated to the NTA level.
* `MSE_histogram_cont_cs_NTA.eps`: a histogram showing the distribution of the ratio of MSEs contrasting the CBM and CSP's predictions across all tracts. The underlying MSEs are computed at the tract level and aggregated for visualization at the NTA level.
* `density_slope_NTA_cont_cs(_slides).eps`: density plots comparing the slope coefficients of tract-level regressions between observed and predicted values under the CBM and CSP models, aggregated at the NTA level for comparison.
* `density_intercept_NTA_cont_cs.eps`: density plots comparing the intercepts of the tract-level regressions between observed and predicted values under the CBM and CSP models. These intercepts are aggregated across tracts within each NTA.
* `median_MSE_cbm_NTA_aggregated.txt`: contains the median MSE of the CBM across all tracts at the NTA level.
* `median_MSE_csp_NTA_aggregated.txt`: contains the median MSE of the CSP across all tracts at the NTA level.


## Code:
* `map_tract_NTA.do`: Takes in the NYC census to NTA tabulation spreadsheet and reformats the census tract codes to be aligned with the format of the census tract data we currently use. 
* `reg_obs_pred.do`: Compares predicted and observed tract-level employment changes in NYC using three model specifications (CSP, CBM, and CBM with prohibitive costs), then aggregates results to the NTA level and outputs a regression table comparing each model’s performance.
* `sum_slope_intercept_MSE.do`: evaluates the predictive performance of the CBM and CSP models at the tract level, and visualizes tract-level regression metrics after aggregating them to the NTA level for summary plots and statistics.

## Input:
* `nyc_20102012_spikes_list.txt`: List of tracts that experienced employment booms in 2010-2012.
* `nyc2012_lodes_wzeros.dta`: Tract-to-tract commuting flows in 2012 from the LODES dataset
* `nyc2010census_tabulation_equiv.xlsx`: Tract-to-NTA crosswalk in Excel format
