# ReadMe

This folder contains two templates used for Stata maptile command.

`output/US_tract_2010/` is tract-level template in US.
`output/US_tract_2010_nyc` is tract-level template in NYC.

## Structure
Within each template, there are three files needed, including  `geoid11_coords.dta`, `geoid11_database.dta`, and `geoid11_maptile.ado`.

## Notes
`output/US_tract_2010_nyc` covers more NYC tracts than `output/US_tract_2010/`. Therefore, for NYC-specific analysis, we use `output/US_tract_2010_nyc`.
