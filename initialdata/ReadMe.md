# initialdata

This task downloads all required raw data used in this project except LODES commuting data (see `tasks/LODES_downloaddata`), including

- American Community Survey commuting matrices
- US Census tract-level geographical information
- ZIP Code Business Statistics
- Transit times from Davis, Dingel, Monras, Morales (2019)
- crosswalks between different geographic units
- Brazil Municipio coordinates from Dingel, Miscio, Davis (2021)
- the replication package of Owens, Rossi-Hansberg, Sartre (2020)
