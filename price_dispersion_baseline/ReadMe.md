# price dispersion baseline

This task summarizes the price distribution using the finite model estimated on 2010 data or using the ex-post regret simulation method and compares the results, including

1. summarizing dispersion of prices, defined as standard deviation of the finite-model commuting equilibrium price across 100,000 simulations divided by the continuum-case rational expectation of that price;
2. comparing price dispersion across two different simulation methods;
3. summarizing absolute percentage-point deviation of realized price based on 100,000 simulations from the continuum-case rational expectations.
